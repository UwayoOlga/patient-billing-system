# Patient Billing System

Patient Billing System is a hospital billing and workflow application with a .NET
backend and a React frontend. The project supports patient registration, staff
roles, billing, payments, prescriptions, disputes, reports, and role-based
dashboards for hospital operations.

## Repository Layout

- `Controllers/` contains the API endpoints.
- `Services/` contains business logic and background tasks.
- `Models/`, `DTOs/`, and `Enums/` define the application data contracts.
- `Data/` and `Migrations/` contain Entity Framework database configuration.
- `hospital-frontend/` contains the Vite and React client application.

# Contribution Notes

Contributions should keep the project stable and understandable.

## Before Changing Code

- Identify the dashboard, controller, or service affected by the change.
- Check whether an existing helper already supports the workflow.
- Keep naming consistent with nearby files.

## Before Committing

- Review the diff.
- Run the most relevant build or smoke check.
- Use a commit message that describes the actual change.

Clear commits make it easier for the team to review progress and understand what
changed.

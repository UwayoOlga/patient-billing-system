# API Smoke Checks

These quick checks help confirm the API is ready for a demo.

- Start the backend without startup errors.
- Open Swagger or the configured API documentation endpoint.
- Log in with a known test user.
- Fetch a patient record.
- Fetch a bill and its bill items.
- Submit a small payment test only in a development database.
- Create and review a dispute using test data.

Use development data for these checks so production-like records are not changed.

# Frontend Smoke Checks

These quick checks help confirm the frontend is ready for a demo.

- Start the Vite development server.
- Load the landing page.
- Log in with each role that will be shown during the demo.
- Navigate between dashboard tabs.
- Confirm data tables render without empty loading loops.
- Open and close the main modal flows.
- Check the browser console for visible runtime errors.

These checks are intentionally simple and should be repeated after visible UI
changes.

# Demo Script

This short flow can be used to demonstrate the project.

1. Start the backend API.
2. Start the frontend development server.
3. Log in with a staff account.
4. Register or open a patient profile.
5. Create or review a bill.
6. Add bill items from the relevant dashboard.
7. Process a payment or open a billing dispute.
8. Review dashboard reports or system activity.

The demo should show how information moves between patient intake, clinical
workflows, billing, payment, and reporting.
